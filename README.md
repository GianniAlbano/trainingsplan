# Trainingsplan

Persönliche Trainingsplan-App für den Berlin-Marathon 2027: Wochen-, Monats- und Halbjahresansicht, Einheiten eintragen, Formcheck ohne KI. Läuft offline und gleicht über Supabase zwischen Geräten ab.

**App:** https://giannialbano.github.io/trainingsplan/

- [ANLEITUNG.md](ANLEITUNG.md) – Einrichtung mit GitHub Pages und Supabase
- [ENTWICKLUNG.md](ENTWICKLUNG.md) – Aufbau, Datenmodell, Arbeitsweise für Änderungen
- [CHANGELOG.md](CHANGELOG.md) – was sich wann geändert hat

Trainingsdaten liegen nicht in diesem Repository, sondern verschlüsselt in Supabase und auf den angemeldeten Geräten.
